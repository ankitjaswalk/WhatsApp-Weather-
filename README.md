# 🌤️ WhatsApp-Weather

This is a simple project that uses the **OpenWeatherMap API** to fetch the weather of a user-specified location, and then sends the weather details (like temperature and conditions) to a **predefined WhatsApp number** using a messaging API like Twilio.

It’s a fun way to get real-time weather updates through WhatsApp!

---

## 📱 How It Works

1. The user inputs a location (e.g., city name).
2. The script fetches weather data from OpenWeatherMap.
3. It formats the data into a user-friendly message.
4. The message is sent to a predefined WhatsApp number using Twilio (or similar).
